装法（摘要，详版见 README.md / NEXT-AI.md）
----------------------------------------------------------------
1. 解压到固定目录
2. powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
   （默认往 <DSH_HOME>\profiles\desktop\node_modules 复制 23 个目录；
     可 -ProfileName / -DshHome / -Force）
3. 改 profile 的 package.json：dependencies 加 "dsh-mnemon": "0.5.39"，
   dsh.profile.bundles 加 "dsh-mnemon"
4. 重启 DSH
5. 侧栏「记忆系统」→ 状态；插件页「可组合记忆」→ 主策略与组件
铁律：不要用 link: 装本地文件夹；@deepseek-ai/*、react、react-dom 由宿主提供。
升级：直接覆盖装，.mnemon 里的记忆不用迁移；做一次 ZIP 备份更稳。

----------------------------------------------------------------
默认数据目录：%USERPROFILE%\.mnemon（可用 MNEMON_DATA_DIR 覆盖）
  runtime\  memories.json（事实源）/ MEMORY.md、USER.md（投影）/
            archived\ / .memories.lock
  documents\ index.json / active\（活跃档案 ≤10MB）/ archived\（不占额度）
  state\    machine.json（本机身份，不进备份）
热记忆容量：MEMORY.md 10KB、USER.md 4KB、单条 8KB；超了自动压缩归档
           （有可写记忆空间就归档进去，没有就落本地 archived\）
storageScope：global（默认）/ workspace / workspaces / custom
