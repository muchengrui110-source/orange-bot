             会建一份极简的，或用本包模板 / 页面里现写

----------------------------------------------------------------
装法（摘要，详版见 README.md / NEXT-AI.md）
----------------------------------------------------------------
1. 解压到固定目录
2. powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
3. cd plugin ; npm pack   → dsh-persona-1.4.0.tgz
4. DSH 插件页 → 添加插件 → 选 tgz → 安装 → 启用
5. 重启 DSH
6. 设置 → 左侧「身份与人设」
铁律：不要从本地文件夹安装（pnpm 只建 link、不装依赖 → failed to import）
