# dsh-persona · 身份与人设（框架版）

DSH 插件：设置里多一页「身份与人设」。读写的是 QQ 桥接的人格文件（默认
`<DSH_HOME>\qq-bridge\personas.json`，`DSH_HOME` 默认 `C:\Users\<用户名>\.dsh`）。

- 编辑身份（默认人格）、每个 QQ 会话的性格模式、共用规则；
- 给一个角色名，自动去萌娘百科 / 360 百科 / 搜索抓资料，用当前模型提炼成人设和说话方式，
  存进角色库，再「套用」成某个会话的模式。

包里带**机制 + 一个性格模板（蓝色示例角色）**：`personas.json` 不存在时，用
`templates/personas.template.json` 初始化；默认人格就是「蓝色示例角色」（DeepSeek 鲸鱼娘的二创人格，
三段式写法），角色库里也带一份同样的资料，内容随便改。

## 1. 安装

前提：这台机器装好了 DSH，最好也装了 `dsh-qq-bridge`（改的就是它的人格文件）。

1. 把 `dsh-persona` 文件夹放到一个固定位置，比如 `C:\Users\<用户名>\plugins\dsh-persona`；别放临时目录。
2. 对 DSH 里的 agent 说：「把 `<上面那个绝对路径>` 装成插件」。它会用
   `plugin_manager action=install_bundle target=<路径>` 安装。
3. 装完重启 DSH（或在插件页启用/热重载）。
4. 打开设置：左下角账号菜单 →「设置」→ 左侧「身份与人设」。

这个包没有第三方依赖，不用联网装依赖，也不占端口。

## 2. 页面能改什么

| 区域 | 对应字段 | 说明 |
|---|---|---|
| 从互联网学习角色 | `characters.<角色名>` | 输入名字 → 后台搜资料 → 模型提炼 → 确认后存进角色库 |
| 角色库 | `characters.<角色名>` | 已保存的角色，可编辑、套用到会话、删除 |
| 身份（默认人格） | `default.title` / `default.prompt` | 没单独配过的聊天用它兜底 |
| QQ 会话人格 | `chats.<会话键>.active` / `.modes` | 每个聊天（`private:<QQ号>` / `group:<群号>`）一套模式，`active` 那个会拼进提示词 |
| 规则 | `rules` | 共用短规则，键值对 |

「套用」= 把这个角色的提示词复制成目标会话的一个模式（模式名 = 角色名）并设为当前生效。
复制之后两边独立：以后改角色不会自动改已套用的模式，重新套用一次才覆盖。

## 3. 蓝色示例角色（默认人格）

- 模板文件：`templates/personas.template.json`，`default` 就是「蓝色示例角色」，`characters` 里也存了一份同样的资料。
- 人格正文是三段式：`你是谁：` / `什么时候开口：` / `说话方式：`。写的是 DeepSeek 那个蓝色鲸鱼标志的
  网友二创鲸鱼娘——聪明但惜力、爱吃白米饭、偷吃 Token 被逮先装傻、叫用户「主人」或「鱼片」。
- 它只在 `personas.json` 还不存在（第一次用）时生效，作为初始内容；已经存在的文件不会被模板覆盖。
- 想给某个 QQ 聊天单独用它：页面上切到那个会话 →「+ 新增模式」→ 把正文粘进去 →「设为当前」；
  也可以直接在角色库里点「套用」。
- 想换性格：直接改这一段；想学新角色就用上面的「从互联网学习角色」。

## 4. 说话习惯（从聊天里学）

你在 DSH 里聊天时，插件会顺手记下**你自己发的消息**有多长、几行、怎么断句（句号/逗号/感叹号/问号/省略号/空格）。
只存数字和统计，**不存原话**，文件是 `personas.json` 旁边的 `speech-habits.json`（可用 `config.speechFile` 改位置）。

- 样本攒到 8 条，页面上「说话习惯（从聊天里学）」会生成一段节奏提示，比如平均多少字一条、一行占多少、爱不爱用句号；
- 可以改这段提示，再点「追加到当前模式」把它接到某个 QQ 会话的人格正文后面（保存后 QQ 下一条消息生效）；
- 「清空统计」只清统计，不改人格文件；
- 桥接/系统拼出来的提示词不会被当成「人打的字」计入。

## 5. 写入规则（宿主半边）

- 只接受本机回环 + DSH 信任栅栏，写操作 fail-closed。
- 保存前自动备份成 `personas.json.bak-YYYYMMDD-HHMMSS`，只留最近 20 份。
- 先写临时文件再原子改名，不会留半个 JSON。
- 文件被别处改过（页面打开后 agent 或手改）→ 返回 409，提示先「重新读取」，不静默覆盖。
- 结构校验：`chats` 必须有模式；`active` 指向不存在的模式时落到第一个模式；
  角色字段统一截断长度；全空角色/坏数据丢掉；不认识的顶层字段原样保留。

## 6. 学习角色的资料源

萌娘百科、360 百科、360 搜索、Bing，都直连、不需要 key；提炼用 DSH 当前默认模型，
也可以在插件配置里写 `provider` / `model` 固定。

360 百科/搜索偶尔会弹验证码（IP 限流），命中会降级用萌娘 + 搜索摘要，学出来会差一点。
学习任务不写盘：结果只在内存里留 30 分钟，点「存入角色库」才写 `personas.json`。

## 7. 和 QQ 桥接的关系

- 默认路径和 `dsh-qq-bridge` 的默认数据目录一致：`<DSH_HOME>\qq-bridge\personas.json`。
- 如果桥接那边改过 `personaFile`，这里也要指到同一个文件：在 profile 的 cordis 配置里
  按 id 覆盖 `dsh-persona` 的 `config.personaFile`，或者直接改包里的 `cordis.patch.yml`，然后重启 DSH。
- 没装 QQ 桥接也能装这一页，只是没有会话在用它。

## 8. 包结构

```
dsh-persona\
  package.json
  cordis.patch.yml        # 插入插件行；personaFile / speechFile / provider / model 可配
  lib\index.js            # 宿主：personas 读写 + /api/learn 任务 + /api/speech 统计
  lib\learn.js            # 学习角色：搜资料、拼语料、调模型提炼
  lib\parse.js            # 网页解析（萌娘/360百科正文、防复制噪声、搜索结果）
  lib\speech.js           # 说话习惯：长度/行数/标点统计 + 节奏提示生成（不存原话）
  lib\client.js           # 设置 →「身份与人设」页面
  templates\personas.template.json  # 唯一的人格模板：蓝色示例角色
  locale\{zh,en}.json     # 插件标题/描述
  icon.svg
  README.md
  LICENSE                 # MIT
```

运行时会在人格文件旁边生成 `speech-habits.json`（说话习惯统计，只存数字）；这个文件不随包带，也不含原话。

## 9. 常见问题

| 现象 | 排查 |
|---|---|
| 设置里没有「身份与人设」 | 插件没装/没启用：插件页看有没有 `dsh-persona` |
| 保存报 409 | 文件被别处改过：点「重新读取」再改 |
| 保存报「信任栅栏不可用」 | 不是从 DSH 自己的页面打开的，或宿主 `connection` 服务不可用 |
| 改了但 QQ 那边没变 | 确认两边 `personaFile` 是同一个文件；确认那个会话的 `active` 模式对 |
| 学习一直卡在搜索 | 本机网络到萌娘/360/Bing 不通；先单独打开网页试试，或换 Bing/搜索源 |
| 文件坏了 | 用最近一份 `personas.json.bak-*` 覆盖回去 |
