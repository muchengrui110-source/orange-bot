# redact-patterns.example.txt —— 脱敏扫描的名单模板
#
# 用法：复制成 redact-patterns.txt，然后把下面注释掉的示例行改成你自己的真实值并取消注释。
#   copy redact-patterns.example.txt redact-patterns.txt
#
# 规则：
#   - 一行一个，整行是纯文本，按「包含」匹配（不是正则），不区分大小写
#   - 以 # 开头的行忽略；空行忽略
#   - redact-patterns.txt 不要进公开仓库（已在 .gitignore 里）
#
# 注意：这份模板故意全是注释。填之前它一条都不会命中——
#       别把「<qq号>」这类占位符当名单用，文档里到处都是占位符，会全是误报。

# 账号：QQ、手机号、群号、学号
# 10001
# 13800000000

# 人名、昵称、角色名
# 张三
# 我的昵称

# 个人绝对路径：写你机器上真实出现过的前缀
# C:\Users\zhangsan
# D:\我的工具

# 域名 / 邮箱
# zhangsan@example.com

# 密钥前缀：写前缀就够，别把值写进来
# ghp_
# github_pat_
# sk-live-
